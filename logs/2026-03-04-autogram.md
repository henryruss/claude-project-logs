## Summary
Built the complete scaffolding for Autogram, an automated Instagram content pipeline targeting a long-distance relationship niche account. The system uses a multi-agent architecture (Claude Opus orchestrator + Sonnet specialists) to research trends, generate quotes/captions, create images via FLUX Schnell, and publish to Instagram — with a training mode where a human approves content to build a preference model before transitioning to fully autonomous operation.

## Tech Stack
- Python 3.12, uv (package manager)
- Claude Agent SDK (claude-opus-4-6 orchestrator, claude-sonnet-4-6 specialists)
- FastAPI + Jinja2 + HTMX + Tailwind CSS (dashboard)
- SQLite with WAL mode + aiosqlite + SQLAlchemy 2.0 async ORM
- Alembic (migrations)
- APScheduler 3.x (8 scheduled jobs)
- FLUX Schnell via BFL API (image generation, $0.003/image)
- Cloudflare R2 via aioboto3 (image hosting)
- Instagram Graph API (publishing + insights)
- Pillow (image quality validation)
- scikit-learn (TF-IDF similarity fingerprinting)
- Pydantic v2 + pydantic-settings
- structlog, tenacity, httpx

## Key Decisions
- **Hub-and-spoke agents**: Orchestrator calls specialists in sequence, no direct agent-to-agent communication; structured JSON output validated through Pydantic at each handoff
- **DB-persisted circuit breakers**: State stored in `system_settings` table so open/closed state survives process restarts
- **Bayesian preference model**: Beta(2,2) prior prevents wild swings on sparse training data; holdout accuracy check gates transition to autonomous mode
- **Human confirms transition**: System flags `transition_ready=true` but never auto-switches modes — human must press button on settings page
- **TF-IDF similarity fingerprint**: Stored as JSON word-freq dict in `posts.content_fingerprint`; cosine similarity compared against last 30 posts before accepting new content
- **InMemoryMCPServer**: Used for agent tool calls rather than stdio-based MCP, keeping architecture self-contained
- **R2 URL verification**: HEAD request with 3 retries after upload before returning URL to agent (avoids IG container creation on unready URLs)

## Lessons Learned
- `statistics.stdev` raises `StatisticsError` on single-value lists; need `len >= 2` guard and also watch for zero-variance populations (all identical values → std=0 → outlier detection breaks)
- Alembic `autogenerate` works cleanly if models are imported before `env.py` runs — the `from autogram.db.models import Base` import in env.py is essential
- `uv init` creates a `main.py` that needs to be deleted to avoid conflicts with `src/` layout
- SQLAlchemy 2.0 async `update()` requires explicit `await session.commit()` — forgetting this silently drops changes
- `{**base, "engagement": 10000}` is correct dict merge order; `{"engagement": 10000, **base}` overwrites the key with base's value
